# SlackQuick — Slack 빠른 입력 도구

Windows·macOS에서 단축키로 템플릿을 골라, 빈칸을 채우고, **서식(굵게·기울임·링크·인용)이 살아 있는 채로** Slack 입력창에 바로 붙여넣는 도구예요.

## 단축키

| 동작 | Windows | macOS |
|---|---|---|
| 템플릿 팝업 | `Ctrl+Shift+Space` | `Ctrl+Option+Space` |
| 서식 직접 입력 | `Ctrl+Alt+F` | `Ctrl+Option+F` |
| 설정 화면 열기 | `Ctrl+Alt+S` | `Ctrl+Option+S` |
| 빈칸 창에서 붙여넣기 | `Ctrl+Enter` | `⌘Enter` |
| 굵게 / 기울임 / 링크 | `Ctrl+B` / `Ctrl+I` / `Ctrl+K` | `⌘B` / `⌘I` / `⌘K` |
| 취소선 / 코드 | `Ctrl+Shift+X` / `Ctrl+Shift+C` | `⇧⌘X` / `⇧⌘C` |

단축키는 설정에서 바꿀 수 있어요. Windows는 입력칸을 누른 뒤 원하는 키 조합을 누르면 돼요. 설정 화면 단축키는 끌 수도 있어요 (Windows: 입력칸에서 Backspace, macOS: 비워 두고 적용).

Windows 버전은 WinUI 3(Windows 11 스타일)로 만들었고, 시스템의 밝은/어두운 테마를 따라가요. 템플릿은 고치는 즉시 자동 저장돼요.

## 서식 문법

| 쓰는 법 | 결과 |
|---|---|
| `*굵게*` | **굵게** |
| `_기울임_` | *기울임* |
| `~취소선~` | ~~취소선~~ |
| `` `코드` `` | `코드` |
| ` ```코드 블록``` ` | 코드 블록 (여러 줄 가능) |
| `[글자](https://주소)` 또는 `<https://주소\|글자>` | 글자에 링크 |
| 줄 앞 `> ` | 인용 |
| 줄 앞 `- ` | • 글머리 목록 (목록 줄에서 Tab 들여쓰기, Shift+Tab 내어쓰기, Enter로 다음 항목) |
| `"따옴표"` `--` `...` `->` `<-` | “따옴표” — … → ← (설정에서 끌 수 있음) |
| `:white_check_mark:` | Slack 이모지 (보내면 Slack이 변환) |

## 빈칸

템플릿 안에 `{{이름}}`을 쓰면 붙여넣기 전에 입력창이 떠요. 같은 이름은 한 번만 물어보고, 마지막 입력값을 기억해요.

자동 빈칸: `{{클립보드}}` `{{날짜}}` `{{시간}}`

### 복사한 서식 그대로 + 멘션

- `{{클립보드}}`는 복사해 둔 내용을 **링크·이모지 서식까지 그대로** 끼워 넣어요. 사내 페이지의 "링크 복사"처럼 여러 링크가 한 번에 복사되는 내용에 써요.
- **멘션:** Slack은 붙여넣을 때 자기 서식 데이터(`slack/texty`)를 읽어요. SlackQuick은 이 형식으로 멘션(사용자·그룹 ID)·목록·인용·링크를 함께 넣어서, `@이름`이 실제 멘션으로 들어가요. Slack 입력창이나 메시지에서 멘션을 복사한 뒤 관리 창의 **멘션**에서 가져오면 등록돼요. Slack에서 복사한 내용을 빈칸 창에 붙여넣기만 해도 그 안의 멘션은 자동으로 등록돼요.
- 입력칸에 **붙여넣기(Ctrl+V / ⌘V)** 할 때도 복사한 글의 링크·굵게·목록이 `[글자](주소)` 같은 문법으로 바뀌어 들어가서, Slack에 링크가 걸린 채로 전달돼요.
- 기본 템플릿 "공유 (멘션 · 복사한 줄 · 전달내용)": `{{멘션}}` / `{{클립보드}}` / `{{전달내용}}`

예시:
```
*[{{태그}}] {{타이틀}}*
{{내용}}

> {{전달내용}}
```

## 팝업 검색

이름·키워드·내용으로 검색하고, 초성(`ㄱㅈ` → 공지)도 돼요. 키워드와 똑같이 입력하면 그 템플릿이 맨 위로 와요. 키워드는 템플릿 관리 창의 이름 옆 칸에서 정해요.

## 설치

[Releases](https://github.com/chowonki/Slack-Quick-Input/releases) (`slackquick-v…` 태그)에서 받으세요.

- **Windows**: `SlackQuick-Windows-x64.exe`를 원하는 곳에 두고 실행 → 트레이 아이콘. 설정에서 "Windows 시작 시 실행"을 켤 수 있어요.
- **macOS 13+**: `SlackQuick-macOS.zip` 압축을 풀고 `SlackQuick.app`을 응용 프로그램 폴더로 옮긴 뒤 **우클릭 > 열기**. 자동 붙여넣기(⌘V)를 위해 **시스템 설정 > 개인정보 보호 및 보안 > 손쉬운 사용**에서 SlackQuick을 켜 주세요. (새 버전으로 바꾸면 권한을 다시 켜야 할 수 있어요.)

## 저장 위치

- Windows: `%APPDATA%\SlackQuick\templates.json`
- macOS: `~/Library/Application Support/SlackQuick/templates.json`

두 버전의 템플릿 파일 형식이 같아서 파일을 그대로 옮겨 쓸 수 있어요.
